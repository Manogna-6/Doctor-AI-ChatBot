# 🐱 AI Medical Chatbot

 AI-powered medical information chatbot built with
Python, Gradio, and the Google Gemini API.

It provides conversational access to general health information
through an interactive web interface.

## Features

- AI-powered health information conversations
- Follow-up questions with conversation history
- General symptom information
- Health and wellness guidance
- Quick questions for common health topics
- Separate health information panel
- Interactive Gradio interface
- Medical safety instructions

## Technologies Used

- Python
- Gradio
- Google Gemini API
- Google GenAI SDK
- HTML
- CSS
